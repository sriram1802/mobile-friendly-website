# Responsive Website Using CSS Media Queries

## Description
This project is a simple responsive website built using HTML and CSS. It uses CSS Media Queries and Flexbox to make the layout adapt to different screen sizes, including desktops, tablets, and mobile devices.

## Features
- Responsive design
- Mobile-friendly layout
- Navigation menu
- Flexbox-based structure
- CSS Media Queries

## Technologies Used
- HTML5
- CSS3
- Flexbox
- Media Queries

## Files
- Website.html
- style.css

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `Website.html` in a browser.
4. Resize the browser window or use DevTools to test responsiveness.
